**Idea 1 result.** `DistinctShapes(DrawByLevel(12, 240))` = 12: no board in the drawn axle chapter is another one turned or mirrored, counting the linked pair. `SameShape` tries all eight symmetries and transforms each cell's port mask with the board (ports N=1, E=2, S=4, W=8; a mirror swaps E and W; `ForkBoards.Rotate` turns clockwise). The test builds turned and mirrored copies with its own helpers, so a direction mix-up in production would fail it.

**Idea 2 review.** Found while reading the code for this run: `TreePlay.PlayedTogether` was just `players > 1`, so setting the token and solving alone saved `MarkTogether` for that thing and its story said it was solved together. Now `TurnLedger.Movers(step)` counts the distinct seats that held the turn before each recorded move up to the current undo step; undone moves drop out because `Record` already forgets later keys. Every board kind builds an undo row, which calls `Track`, so real shared solves still count. The implementer lit pips `0..movers-1`, which could light a seat that never moved (seats 1 and 2 moved, seats 0 and 1 lit). The coordinator added `TurnLedger.Moved(seat, step)` so only the seats that moved light up, with tests. Three source pins in `SpokenTurnTests` and `SolvedTogetherTests` asserted the old text and were updated to the new behaviour. Undercounting is the safe direction: someone who helps only by pointing isn't counted.

**Idea 3 review.** `TakeTurns.TableCaption` matches `NextPlayers` for 1 to 4 (tested). The caption is attached with `LongPressCaption.AttachLive`, which reuses the caption `Token()` already added, so it is read at the moment of the hold. The implementer moved the attach into a small `TableRow` helper in `TreePlay.Turns.cs` to keep `TreePlay.cs` at its pinned 1,099 lines.

**Idea 4 review.** 9/11/13-point pips, 12/14/16 apart; four pips span at most 61 points under the 52-point token. Nobody has seen it at 150%.

**Idea 5 review.** The new overload only adds a sentence when one of `world.Choices` maps to the same catalogue art through `GardenCatalog.For`, the same mapping `Companion` and `DayRhythm` use. It never adds a negative sentence, so a nursery copy in the garden stays silent rather than wrong. Reading never changes the save (byte-identical snapshot test).
