# Numberlink Paths — independent game design system (v0.1)

**Positioning:** a calm, approachable and original Numberlink experiment; no medical/cognitive outcome claims, age stereotypes, timer, streak trap or purchase prompt.

**Three adjectives:** woven · directional · grounded.

| Role | Color | Purpose |
| --- | --- | --- |
| Paper | `#FAF8F0` | Main background |
| Ink | `#28434D` | Numbered clues, text, and labels |
| Accent | `#255C75` | Focus, primary buttons and active marks |
| Pale | `#E5EEDF` | Alternative puzzle states and non-primary controls |
| White | `#FFFFFF` | Editable cells and high-contrast text |

**Type:** native/system fallback; 28px title, 15–17px rule/status, 14–21px cell captions, 13px secondary. **Spacing:** 16px horizontal gutters, ~12px rhythm, 4px between cells; interactive cells are 53px (5×5 fleet) or 76px (4×4 games), each action ≥54px. Scroll on short screens, not tiny controls.

**Puzzle feedback:** Tap blank cells A → B → empty; fixed endpoints are marked with circles, and each route has its own letter and color. The board uses text/letters/numbers as well as color to distinguish states; the visible rules engine checks exact constraints. Incorrect choices display a specific rule warning where possible, without manipulating player input. Undo and Restart always visible.

**Motion:** instantaneous reversible presses; no forced animation or time pressure. **Audio and haptics:** absent; later opt-in testing only.

**Icon brief:** two interlacing but noncrossing blue and amber routes joining pairs of large endpoint dots. Original vector/iconography; do not reuse competitor logos or artwork.

**Screenshot plan:** empty endpoint grid, midway assigned A/B routes, a branch warning, completed partition. No real phone screenshots have been captured.

**Accessibility:** minimum 53px touch targets, native focusable buttons, cell row/column accessibility labels and readable text. True nonvisual spatial puzzle equivalence, contrast at 200% text, safe-area and VoiceOver/TalkBack testing must be verified on actual devices before distribution.

**Original content:** six independently authored, exact-rule uniquely-solvable fixtures. This visual system alone is **not** a defensible differentiator. User preference, return behavior, search intent, distribution cost and monetization are all unmeasured.
