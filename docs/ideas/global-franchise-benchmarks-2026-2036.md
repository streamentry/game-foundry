# 50 genre trendsetter references: competitive mechanics watchlist (2026–2036)

**Source:** founder-supplied speculative list, captured 2026-11-22. **Not** a verified ranking, release calendar, financial forecast, ownership map, or collection of original games to copy.

This is a **benchmark library** separate from [the 50 original GC ideas](global-concepts-2027-2036.md), [12 cross-genre GX experiments](four-genre-outlook-2026-2036.md), and [100 GF keyword hypotheses](candidates.csv). Some rows bundle multiple titles or hypothetical successors; each row is a *watchlist entry*, not evidence of a real announced game or an additional build commitment.

## Reading rules

- Retain user-provided mechanics as hypotheses when the product is unreleased or details are unverifiable. Several entries explicitly name imaginary sequels; **do not present them as announced**.
- Do not assume Roblox, Fortnite, GTA, Pokémon or other owned franchises can be reproduced, commercially branded, or monetized with their assets.
- Grouped references are not necessarily from the same publisher: **Ananta / Project NTE must not be attributed to HoYoverse** merely because they appeared on one line.
- Favor lessons achievable by a small team. Studio target remains 45+ unless a separate audience experiment is deliberately approved.
- Watchlist selection is observational only. This does not change current market-search or player-test gates.

## Next evidence pass

For each prioritized reference, capture **official release/product status**, developer/publisher, platforms, source date, verified core loop, observed audience, monetization, acquisition mechanism, retention evidence if available, user complaints, IP restrictions and a falsifiable *original* mechanic hypothesis. Leave unavailable values unknown. Do not convert predictions into factual claims.

**Stop condition:** if a copied mechanic offers no distinguishable player value or realistically accessible distribution, do not build it regardless of global franchise popularity.
