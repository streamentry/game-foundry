# I70 — First-session kit updated for 40+ with predeclared design bets

Date: 2026-11-24. Branch: feat/mosselora-painted-ui (PR #76).

**Why.** The remaining question is whether this design is actually great for people aged 40+, and screenshots and AI proxies cannot answer it. Four AI reviews and a proxy walkthrough have done what they can: the fresh review scored immersion 8, polish 8, navigation 7, fit for 40–49 7, icon-first 6 and daily appeal 5, and the proxy found the first-board risk (fixed in I64).

**Change.** The existing M3 first-session kit (`docs/playtest/m3-session-kit.md`, plus the recruitment kit) is updated for the **40+** audience (bands 40–49 · 50–64 · 65+). It gains a **painted-build addendum**: nine predeclared observations (P1–P9), each tied to the iteration that made the bet. They cover the icon-only hub arrow, the picture coach and glowing goals, icon-only tools, droplets and mouths, picture-first choices, memory recall, menu discovery, return on day 2 and motion comfort. Each has a fail threshold and a **reversal rule** that falls back to the more explicit option already recorded in that iteration's log.

**Next real step (needs people, not code).** Run 8–12 uncoached sessions per the kit on real phones, report each band separately, and let P1–P9 decide which bets stay.
