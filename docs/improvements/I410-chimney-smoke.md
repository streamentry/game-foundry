# I410: Chimney smoke

Run 3, batch 15.

On cold evenings, nights and dawns (autumn, winter, or any snowy day), the cottage fire is lit: three soft puffs rise and fade from the chimney, one after another. With the lamp in the window (I296), it says that someone is home.

- `DayLight.ChimneySmoke(phase, season, weather)`, tested.
- `ChimneyWisp`: puffs rise for four seconds each, drifting and fading. Still when motion is off.
