# I389: Spring, a flower bed sows itself

Run 3, batch 11.

In spring, a flower bed (two different flowers side by side, I368) self-seeds: a flower cutting appears in the basket, ready to plant. It's the same cutting mechanism family and neighbours use (`ReceiveNeighbourCutting`), and the basket's 50-item cap applies. The toast shows flower → sprout → basket.
