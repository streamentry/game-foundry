# I426: Bees heard

Run 3, batch 18.

When the bees have come (three flowers, I325) and are out in today's weather (I405), the day's soundscape sometimes carries a bee passing: a soft buzz that swells, wavers as it turns, and fades. It's chosen a quarter of the time, so it's noticed rather than constant.

- `AmbientVoice.Bees` (synthesised, about 220 Hz with harmonics) and `SecondsBetween(Bees) = 10`. Tested to be rarer than birds.
