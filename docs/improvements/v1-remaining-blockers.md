# v1 checklist: what blocks the remaining 34 items (2026-11-28)

The [checklist](100-improvements-v1.md) has 66 of 100 items ticked after batches 1–33. Each remaining item's own *Test* needs something this coding environment cannot produce. None is blocked on code that could be written here without that input. This page says what each one waits for, so nobody has to rediscover it. The rule stays: tick only when built **and** its test has run.
