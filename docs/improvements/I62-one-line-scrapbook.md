# I62 — Scrapbook pages say one remembered sentence

Date: 2026-11-24. Branch: feat/mosselora-painted-ui (PR #76).

**Player problem (I51 and I60 finding 3).** Scrapbook pages carried the full chapter record ("Chapter 4 · Orin · Restore a crossing / The crossing connects both banks. / Bridge foundations anchor this pipe…"), dense reading for a keepsake page.

**Change.** Each page shows **one remembered sentence** under its painting and keeper portrait ("Orin remembers the bridge you restored."). The order of the pages already gives the chapter. The full record stays on the page as transparent, out-of-layout text, so screen readers still speak the complete history.

**Evidence.** b39 QA tour, journal sheet (`I62-one-line-scrapbook.png`, right): four pages, each a picture, a face and one sentence.
