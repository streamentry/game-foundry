# I58 — Rooted tiles show the painted landmark that holds them

Date: 2026-11-24. Branch: feat/mosselora-painted-ui (PR #76).

**Player problem (I51 note).** The protected tile carried an abstract procedural badge that a reviewer read as "a letter". The tile is rooted *by something the player chose*, so it should show that thing.

**Change.** Over the badge, the protected tile now shows the **painted landmark that holds it**: the tree, bridge or wildflowers (the same Codex choice icons), at 46% of the tile in its top-left corner. It is picked from the board variant, which is the previous choice + 1, so it is always the truthful cause. The heavy bark frame and the spoken rule are unchanged.

**Vision fit.** §3: "your choice changes the next puzzle", now visible on the very tile it changed.

**Evidence.** b36 tour, stream 2 after "Plant a shade tree" (`I57-I58-pictogram-coach-rooted.png`, right).
