# I361 — The name beyond the mist

Run 3, batch 5.

## PM decision

Above the drops on the mist (I224), the name of the stretch waiting beyond it shows faintly, in italics: a place to walk toward, not just "more".

## Dev

- `GardenMapView.ShowDrops` adds a faint italic label with `RiverNames.For(reaches)`, the next stretch's name, and replaces it when the drops refresh.

## Result

Progress has a destination. If the river is at its ceiling, there are no drops and no name, as before.
