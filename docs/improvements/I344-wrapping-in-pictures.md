# I344 — Wrapping in pictures

Run 3, batch 2 (P2).

## Player

"'No envelope' and 'No stamp' are words where pictures would do."

## PM decision

The wrapping step is all pictures:
- a sealed envelope token for a wish (seeds, fruit or jam);
- a stamp token that shows the stamp itself.

Nothing chosen shows the plain token, with no "No envelope" words. The only words are the wish itself, in envelope red, because that's what the relative will read.

## Dev

- `FamilySheet.BuildWrapStep` uses larger tokens (72) with the painted envelope and the stamp art at 56. The "No …" labels are removed.

## Result

Fewer words, same choices.
