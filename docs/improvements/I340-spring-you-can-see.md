# I340 — Spring you can see

Run 3, batch 1.

## Player

"Spring and summer looked the same apart from a few petals."

## PM decision

In spring, trees blossom: pink and white flowers in their upper branches. The petals drifting over home are fuller (20). Flowers bloom; the year is starting.

## Dev

- `ThingLook.Blossom` for trees in spring (tested).
- `DressForSeason` places nine blossom dots in the upper canopy, two pinks and a white, at fixed positions so a tree looks the same each visit.

## Result

Spring differs from summer at a glance.
