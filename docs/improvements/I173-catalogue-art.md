# I173 — 200 painted trees, flowers and buildings

Date: 2026-11-25. Branch: feat/mosselora-i127-plus.

## Player

The catalogue (I171) needs 200 pictures, each recognisable at a glance and each looking hand-made in the same storybook style as everything else. "Hand-made, not generated-looking" is rule 2 of the end-game taste charter.

## Art (Codex image generation)

8 sheets of 25 icons (5×5), one per prompt (`art/prompts/catalog-{trees,flowers,builds}-{a..}.txt`). Each prompt lists the items in grid order and uses the existing tree, bridge and flower icons (`icons-choices.png`) as the style reference: watercolour, soft outlines, warm light, a three-quarter view on a small patch of grass or stone, and a transparent background.

**Reviewed by eye, sheet by sheet** (`I173-all-200.jpg`, gitignored): every cell matches its name and order.
- **Trees:** apple, pear, cherry, plum, quince … silver birch, weeping willow, oak … sugar maple, red maple, ginkgo … jacaranda.
- **Flowers:** lavender, sunflowers, poppies … foxgloves, hollyhocks … water lilies on their pads … anemones.
- **Builds:** stone bridge, footbridge, stepping stones, mill wheel, windmill … bug hotel, hedgehog house … forge, pottery kiln, weaving shed … paper lanterns, wind chimes, cascade steps, rain shelter.

No sheet needed regenerating. One note: the post box is drawn as a generic red pillar box, with no royal cipher or text.

## Dev

`tools/evergrove_art_pipeline.py` slices each sheet on a 5×5 grid, trims, fits to 192px and saves `tree-00..49`, `flower-00..49` and `build-00..99` (+ `.meta`) in `Resources/Evergrove/Art`. All other sprites regenerated byte-identical.
