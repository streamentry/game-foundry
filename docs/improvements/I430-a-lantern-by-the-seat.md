# I430: A lantern by the seat

Run 3, batch 19.

Once a garden has its shady seat (I380), a small lantern stands beside it. From dusk it is lit: a warm glow that breathes when motion is on. It's where the neighbours sat in the golden hour (I402), now marked for the evening. It reuses the lantern painting family leave (I310), so the garden's language stays consistent.

- `GardenMapView.SeatLanternNext` is set on home from `Pairings.SpotFor(..., ShadySeat)` once the pairing has been found.
