# I420: Welcome back

Run 3, batch 17.

After a week or more away, Mira's first line (I359) begins with reassurance: "It's good to see you. Nothing's lost while you were away." After a month: "There you are. It's been a while, and that's all right: nothing's lost, the garden kept itself." Then comes the weather you missed.

The game never punishes absence (nothing wilts, nothing is taken), and now it says so. For players over 40 with full lives, coming back should feel easy, never like catching up.

- `Companion.WelcomeBack(daysAway)`, using the device-only last-seen date already kept for I359. Tested: none under a week; never "miss"; always says nothing is lost.
