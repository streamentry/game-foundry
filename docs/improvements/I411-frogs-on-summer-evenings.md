# I411: Frogs on summer evenings

Run 3, batch 15.

On summer dusks, the soundscape (I316) carries a few low frog croaks with the crickets. The creek loop already carries the water, so the soundscape keeps its rule of one or two voices at a time.

- `AmbientVoice.Frogs` is synthesised: three buzzy pulse trains around 180 Hz, each dropping slightly in pitch.
- `Soundscape.For(Summer, Dusk)` gives frogs and crickets. Tested: summer dusk only.
