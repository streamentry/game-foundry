# Store asset concepts

The `concepts/` folders contain eight original AI-generated promotional-art concepts, one for each current game. The Good Eye artwork is a wide, textured shape-splitting motif; each other concept reflects its game's mechanic.

These are concept art only. They are not gameplay screenshots, app previews, approved icons, or upload-ready store graphics. Capture screenshots and preview footage from the actual signed build. Validate dimensions, text, safe areas, readability, and each store's current asset rules before using any concept in a listing.

## Native proof capture

Each of the eight games has an Android emulator screenshot and short recording under its native-proof/android-api36-pixel7-avd/ folder. These show temporary debug builds on an Android 16/API 36 Pixel 7 virtual device. They are evidence of local builds only, not physical-device QA or upload-ready store media. No iOS screenshot or preview footage was captured because the iOS Simulator template could not link for arm64.

Browse the eight captured pairs in the [Android native proof index](native-proof-index.md).
